# Sampada ko Adara (सम्पदाको आधार)
Give 5 minutes. Save a voice. A website that teaches Nepal's regional languages and lets anyone help preserve them.

## Run it
Double-click `index.html`, or in VS Code install the "Live Server" extension, right-click `index.html` and choose "Open with Live Server".

## Files
- `index.html`: home page (top bar, auto-swiping banner, footer)
- `about.html`: About us page
- `style.css`: colors, fonts, layout
- `script.js`: the SLIDES list (edit banner here), carousel and newsletter box
